# 血液培養 S. aureus／CoNS 批次預測工具

BACTEC FX 生長曲線（.xls）整批匯入 → 每瓶 S. aureus 預測機率 → 對照真實菌種算出準確度 → 用新資料更新模型。

**線上使用：** https://kun-hao0607.github.io/bc-sa-cons-tool/

## 隱私

所有檔案只在使用者自己的瀏覽器內讀取與計算，**不會上傳到任何伺服器**。頁面本身不含任何病人資料；內建的建模資料只有 TTD、瓶別、rt2080、菌種類別與匿名分組編號。

## 模型（v1）

```
logit = 9.478 − 4.459 × ln(TTD) + 1.678 × 厭氧瓶 + 0.196 × rt2080
P(S. aureus) = 1 / (1 + e^−logit)
```

- 建模資料：單一醫院 2026 年 10 月，156 瓶（S. aureus 44 瓶）。
- 依病人分組交叉驗證 AUC 約 0.78。
- 未經外部驗證，機率未經校準。

## 限制

研究用途，不能取代培養鑑定，也不能作為臨床決策的唯一依據。
